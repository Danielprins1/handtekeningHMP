# Holy Moly Pizza, e-mailhandtekeningen

Statische hosting voor de e-mailhandtekeningen van Holy Moly Pizza.

## Wat zit erin

- `index.html` de pagina met alle personen, keuzemenu en kopieerknop
- `holymoly-logo.png` het logo, 300x300 met transparante hoeken
- `handtekening-alfie.html`, `handtekening-galit.html`, `handtekening-cammie.html`, `handtekening-daniel.html`, `handtekening-leon.html` losse bestanden per persoon
- `README.md` dit bestand

## Gebruik

Open de Pages-URL, bijvoorbeeld `https://danielprins1.github.io/handtekeningHMP/`.
Kies bovenaan een persoon, klik op "Kopieer handtekening voor Mail en Gmail" en
plak in het handtekeningvak van Apple Mail of Gmail met Cmd+V.

## Bijwerken op GitHub

Upload de gewijzigde bestanden naar de repo en overschrijf `index.html`. De
pagina detecteert de logo-URL automatisch, ook als de repo anders heet.
